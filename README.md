# IMora - Indra Utomo Putra

Portfolio website for Data & Information Management, GIS, and Emergency Response.

## Stack

- HTML + vanilla JS + Tailwind CSS v3 (CLI build), neo-brutalist style
- Motion (self-hosted in `vendor/motion/`) for animations, Font Awesome icons
- Dual-language (ID/EN), light/dark theme
- Downloadable CV: `cv/cv.html` → `assets/CV-Indra-Utomo-Putra-Syarif.pdf`

## Dev

```bash
npm install
npm run build    # rebuild css/tailwind.css from src/input.css
```

Open `index.html` in a browser (no dev server needed), or run `npm start`.
