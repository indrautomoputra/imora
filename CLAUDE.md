# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

Static single-page portfolio site (imora.site) for Indra Utomo Putra. Plain HTML + vanilla JS + Tailwind CSS v3, no bundler, no framework, no tests or linter. Deployed as static files via GitHub Pages (`CNAME`, `.nojekyll`).

## Commands

```bash
npm install
npm run build    # compile src/input.css -> css/tailwind.css (minified)
npm run watch    # same, rebuild on change
npm start        # npx serve .  (or just open index.html directly)
```

`css/tailwind.css` is committed build output — rerun `npm run build` after adding new Tailwind classes or editing `src/input.css`, otherwise the classes won't exist on the live site.

## Architecture

Scripts load as plain globals in this order (`index.html` bottom): Motion (self-hosted UMD, `vendor/motion/motion.js`, motion@12.43.0, global `Motion`) → `data/portfolio-data.js` → `data/i18n.js` → `js/script.js`. A tiny inline script in `<head>` sets `data-theme` and the `.js` class before first paint. All `localStorage` access is wrapped in try/catch (it throws when site storage is blocked).

- `data/portfolio-data.js` — Indonesian content for the JS-rendered sections: `profile` (stats, About quick facts, skills grouped by category), `certs`, `products`. Static text (hero, about, contact) lives directly in `index.html`.
- `data/i18n.js` — `en` object with English translations, plus the global `currentLang` (from `localStorage`, default `"id"`).
- `js/script.js` — `render*()` functions build the dynamic sections from the data via template strings; `applyLang()` re-renders everything on language switch; theme toggle sets `data-theme` on the root and persists to `localStorage`.

### i18n model

- Indonesian is the default and lives in the HTML / data files. English is an overlay: `tr("dot.path")` looks up `en` and returns `null` in ID mode, callers fall back to the Indonesian value.
- Static HTML text uses `data-i18n="key.path"`; the original Indonesian text is cached in `data-i18n-id` on first switch.
- Product type labels translate via `en.types[type]`.
- Products are translated **by array index** (`en.products[i]` ↔ `products[i]`), and skill group names by their Indonesian key (`en.skillGroups["GIS & Pemetaan"]`). Reordering/adding items in `portfolio-data.js` requires the matching change in `i18n.js`.
- `en.certs` replaces the whole `certs` list in EN mode.

### Theming

Neo-brutalist style: thick `--ink` borders, hard offset shadows, flat `--pop-*` colors, no blur. Fonts are Archivo Black (`font-display`) and Space Grotesk (`font-body`). Readability rules: body text sits on plain surfaces (`--surface` / `--bg`), is never rotated, and stays around 65ch wide; decoration (dots, rotation) goes on non-text elements only.

Colors are CSS variables in `src/input.css` (`:root` = light default, `[data-theme="dark"]` overrides). `tailwind.config.js` maps `bg`, `fg`, `muted-fg`, `ink`, `surface`, `accent`, `on-pop` and `pop-*` to them. `pop-*` colors are the same in both themes; text on them uses `text-on-pop`. Tailwind's `/opacity` modifier does **not** work on these var colors.

Reusable pieces in `@layer components`: `nb-card`, `nb-hover`, `nb-btn`, `nb-tag`, `nb-kicker` (numbered section label), `nb-highlight`.

### Animation (Motion)

All animation lives in `initMotion()` in `js/script.js`, driven by markup attributes:
- `data-reveal` fades/slides an element in when it scrolls into view.
- `data-stagger` on a container animates its children in sequence, then adds `.is-in` so children re-rendered later (language switch) show at once.
- `data-count` / `data-suffix` (emitted by `renderStats`) tick numbers up.
- `#hero-name` is split into words that slide up.

Motion writes an inline `transform`, which overrides the `nb-hover` / `nb-btn` hover transforms. Never put `data-reveal` on, or make a `data-stagger` child of, an element that uses those classes; wrap it in a plain `<div>` (see `renderProducts`).

These elements start at `opacity: 0` only under `.js` and `prefers-reduced-motion: no-preference`; with reduced motion, `initMotion()` returns early and everything is visible. Keep the two in sync when adding new hidden-until-animated elements.

### Tailwind content gotcha

`tailwind.config.js` only scans `./*.html` and `./js/**/*.js` — **not `data/`**. Classes that only appear in data files won't be generated. Put class strings in `js/script.js` (e.g. `TYPES` maps product `type` → icon + pop color). Skill icons in data are bare Font Awesome names (`fa-map`, gets `fas`) unless they carry their own prefix (`fab fa-react`).
